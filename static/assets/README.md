# Logo oficial

Colocar aquí `talca-logo.svg` o `talca-logo.png`. Se intenta SVG primero y PNG después.
El navegador lo muestra automáticamente al recargar. Si ninguno existe, aparece
TALCA como texto común, sin imitar ni redibujar el logo. Preferir fondo transparente
y comprobar su legibilidad sobre el encabezado azul #0439AC.

Rutas públicas: `/assets/talca-logo.svg` y `/assets/talca-logo.png`.
